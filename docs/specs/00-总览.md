# 00 总览与已定决策

## 0.1 产品一句话

浏览器里直接玩的写实风格拟真赛车。单人计时赛：3 辆车 × 2 条原创赛道，有幽灵车和本地最佳成绩。支持键盘、手柄、触屏。

## 0.2 已定决策（不得更改）

| 项目 | 决定 |
|---|---|
| 平台 | 网页。桌面端 Chrome/Edge/Firefox/Safari 最新版，移动端 iOS Safari 16.4+、Android Chrome |
| 渲染 | Three.js（WebGL2），不使用 WebGPU |
| 物理 | 自研车辆物理（`reference/sim_reference.py` 的 TS 移植），不使用任何物理引擎 |
| 玩法 | 计时赛（练习模式）：不限圈数，记录每圈时间、分段时间和最佳圈 |
| 对手 | 无 AI 对手，只有幽灵车（自己的最佳圈回放） |
| 联网 | 无。不需要服务器，存档放在 localStorage |
| 车辆 | hatch「雨燕 GTi」（前驱）、coupe「朱雀 R」（后驱）、rally「雷隼 AWD」（四驱） |
| 赛道 | valley「云杉谷环线」2.68 km 晨间；coast「灯塔海岸」2.85 km 黄昏 |
| 画面 | 写实：PBR 材质、HDRI 环境光、实时阴影、后期处理（SMAA、Bloom、Vignette） |
| 素材 | 由用户提供（规格见 `09-素材规范.md`）。**素材缺失时一律用占位方案，游戏必须照样能玩** |
| UI | HTML/CSS 覆盖层，不用 UI 框架。只做简体中文 |
| 单位 | km/h、米、分:秒.毫秒（`1:23.456`） |
| 画质 | 低 / 中 / 高 + 自动，见 `10-性能与画质.md` |

## 0.3 不做的事（第一版范围外）

AI 对手、多人联机、比赛模式（多圈排名）、车辆改装与调校界面、天气变化与昼夜循环、损伤系统、回放系统（幽灵车除外）、驾驶舱视角、方向盘力反馈、多语言。

## 0.5 坐标与单位约定（全项目统一）

- 世界坐标：右手系，**+Y 向上**。长度单位为米，时间单位为秒，角度在内部一律用弧度（只有 JSON 数据里用 `Deg` 后缀表示度）。
- 车身局部坐标：**+Z 向前，+Y 向上，+X 向左**。原点在质心（CoM）。
- 转向输入：`steer > 0` 表示**向左**转。
- 赛道横向偏移 `d`：`d > 0` 表示在行驶方向的**左侧**。
- 四元数：物理层用 `[w, x, y, z]` 数组；与 three.js 交互时转换成 `new THREE.Quaternion(x, y, z, w)`，**注意顺序**。
