# 01 技术栈与目录结构

## 1.1 运行环境

- Node.js 22（LTS），npm 10。
- Python 3.10+（仅用于运行 `reference/gen_golden.py`，游戏本身不依赖 Python）。

## 1.2 依赖（精确版本，不许增减）

| 包 | 版本 | 类型 | 用途 |
|---|---|---|---|
| three | 0.169.0 | dependencies | 渲染 |
| postprocessing | 6.36.4 | dependencies | 后期处理（SMAA/Bloom/Vignette/ToneMapping/FXAA） |
| typescript | 5.6.3 | devDependencies | |
| @types/three | 0.169.0 | devDependencies | |
| @types/node | 22.9.0 | devDependencies | |
| vite | 5.4.11 | devDependencies | 开发服务器与打包 |
| vitest | 2.1.5 | devDependencies | 单元测试 |
| @playwright/test | 1.48.2 | devDependencies | 端到端测试 |
| @gltf-transform/cli | 4.1.1 | devDependencies | 素材优化脚本 |
| @gltf-transform/core | 4.1.1 | devDependencies | 素材校验脚本读取 glb |

Meshopt 解码器直接用 three 自带的 `three/examples/jsm/libs/meshopt_decoder.module.js`，不另外安装。
