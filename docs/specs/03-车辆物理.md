# 03 车辆物理

## 3.1 总原则

- `reference/sim_reference.py` 是**唯一的算法来源**。TS 版逐函数移植，变量名、执行顺序、常数一律照搬。
- 不许"优化"公式，不许调换步骤顺序，不许合并或拆分步骤（golden 测试对顺序很敏感）。
- 物理层只用 `src/math/*`，不许 import three。

### 3.2.1 移植时的逐条注意事项

1. Python 的 `w["xxx"]` 字典对应 TS 的 `WheelState` 对象字段，`self.c` 对应 `this.cfg`。
2. `getattr(self, "revTimer", 0.0)`：TS 里 `revTimer` 是状态字段，`reset()` 时设为 0。
3. `w["rot"] = (w["rot"] + w["omega"] * dt) % (2 * math.pi)`：TS 写成 `((x % TWO_PI) + TWO_PI) % TWO_PI`。
4. `max(..., default=0.0)`：driven 轮数组不会为空，直接用 `Math.max(...arr)`。
5. Python 的 `range(int(10 / DT))` 等于 2400。测试里用 `Math.round(10 / PHYSICS_DT)`。
6. Python 的 `math.atan` 对应 `Math.atan`，`math.atan2` 对应 `Math.atan2`，`math.radians(x)` 写成 `x * Math.PI / 180`。
7. `step()` 里 `a = inp.get("assists", ...)`：TS 的 `DriveInput.assists` 是必填字段，直接使用。
8. `inp.get("handbrake", 0.0)`、`inp.get("shift", 0)` 也是必填字段，直接使用。
9. 车轮状态里的 `contactPoint/normal/f/l/r/vx/vy` 在 `reset()` 时初始化为 `[0,0,0]` 或 `0`。

## 3.3 golden 测试（T13 实现）

文件：`tests/unit/physics.golden.test.ts`

```ts
// 输入脚本：必须与 reference/gen_golden.py 的 script(t) 完全一致
function script(t: number) {
  if (t < 2.0) return { steer: 0.0, throttle: 0.0, brake: 0.0, handbrake: 0.0 };
  if (t < 6.0) return { steer: 0.0, throttle: 1.0, brake: 0.0, handbrake: 0.0 };
  if (t < 8.0) return { steer: Math.min(1.0, (t - 6.0) / 2.0) * 0.3, throttle: 0.5, brake: 0.0, handbrake: 0.0 };
  if (t < 9.0) return { steer: 0.3, throttle: 0.0, brake: 1.0, handbrake: 0.0 };
  return { steer: -0.2, throttle: 0.3, brake: 0.0, handbrake: 0.0 };
}
const ASSISTS = { abs: true, tcs: true, esc: false, autoGear: true };
```

流程：对每辆车 `new Vehicle(cfg, flatGround)`，`k` 从 0 循环到 2399：`t = k * PHYSICS_DT`，`step({...script(t), shift: 0, assists: ASSISTS}, PHYSICS_DT)`；每当 `(k + 1) % 120 === 0` 时，和 golden 里的下一个 sample 比较。

容差：

| 字段 | 绝对误差上限 |
|---|---|
| `kp`、`ap`（只比一次） | 1e-9 |
| `pos` 每个分量 | 1e-3 m |
| `q` 每个分量 | 1e-4 |
| `vel`、`angvel` 每个分量 | 1e-3 |
| `rpm` | 0.5 |
| `gear` | 必须完全相等 |

如果超差：**第一个**超差的 sample 打印出全部字段的差值。先逐行对照参考实现排查，不许改容差。

## 3.5 固定步长循环 —— `src/physics/world.ts`

```ts
export class PhysicsWorld {
  vehicle: Vehicle;
  prev: { pos: V3; q: Q };              // 上一步的位姿（用于插值）
  accumulator = 0;
  constructor(vehicle: Vehicle);
  /** 每个渲染帧调用一次。frameDt 先截断到 0.1 s。 */
  advance(frameDt: number, getInput: () => DriveInput, afterStep: (dt: number) => void): void;
  /** 渲染插值系数 alpha = accumulator / PHYSICS_DT */
  interpolated(): { pos: V3; q: Q };
}
```

`advance` 的算法：

```
frameDt = min(frameDt, 0.1)
accumulator += frameDt
steps = 0
while accumulator >= PHYSICS_DT and steps < MAX_STEPS_PER_FRAME:
    prev = { pos: copy(vehicle.pos), q: copy(vehicle.q) }
    inp = getInput()
    vehicle.step(inp, PHYSICS_DT)
    { impact } = resolveBarriers(vehicle, track, track.data.runoffWidth)   // 3.6，返回 { maxPen, impact }
    lastImpact = max(lastImpact, impact)   // world 的字段；每帧由镜头抖动和音效读取，然后清零
    resolveBodyGround(vehicle, track.query) // 3.7
    afterStep(PHYSICS_DT)                  // 计圈、幽灵车采样等
    accumulator -= PHYSICS_DT
    steps += 1
if steps == MAX_STEPS_PER_FRAME: accumulator = 0   // 掉帧时丢弃剩余时间
```

插值：`pos = lerp(prev.pos, cur.pos, alpha)`；`q` 用 nlerp：`qNorm(lerp4(prev.q, cur.q', alpha))`，其中 `cur.q'` 在 `dot(prev.q, cur.q) < 0` 时整体取负。

`shift` 输入只在**一个**物理步里为 ±1：由 inputManager 产生"边沿事件"，`getInput()` 取走后清零。

## 3.6 护栏碰撞 —— `src/physics/collision.ts`

参考实现里没有这部分，算法如下：

**碰撞点**：车身局部坐标下 6 个点。`halfLen = 2.15`、`halfWid = 0.90`（三辆车相同），`y = 0`（质心高度）：

```
P0 = [ +halfWid, 0, +halfLen ]   左前
P1 = [ -halfWid, 0, +halfLen ]   右前
P2 = [ +halfWid, 0, -halfLen ]   左后
P3 = [ -halfWid, 0, -halfLen ]   右后
P4 = [ +halfWid, 0, 0 ]          左中
P5 = [ -halfWid, 0, 0 ]          右中
```

**每个物理步**（在 `vehicle.step` 之后）对 i = 0..5 依次执行：

```
Pw = pos + qRot(q, Pi)
proj = track.project(Pw.x, Pw.z);  if proj == null: continue
limit = proj.hw + track.data.runoffWidth          // 护栏所在的横向偏移
pen = |proj.d| - limit
if pen <= 0: continue
left = track.leftAt(proj)                          // 投影点处的水平左向量（已归一化）
n = mul(left, -sign(proj.d))                       // 指回赛道内侧的水平法线
r = sub(Pw, pos)
vp = add(vel, cross(angvel, r))
vn = dot(vp, n)
if vn < 0:
    // 世界系惯量的逆：Iinv_world(x) = qRot(q, Iinv_body ⊙ qInvRot(q, x))
    rn = cross(r, n)
    k = 1/mass + dot(n, cross(IinvW(rn), r))
    jn = -(1 + 0.2) * vn / k                      // 恢复系数 e = 0.2
    // 切向摩擦
    vt = sub(vp, mul(n, vn)); vtLen = length(vt)
    J = mul(n, jn)
    if vtLen > 1e-4:
        t = mul(vt, 1/vtLen)
        rt = cross(r, t)
        kt = 1/mass + dot(t, cross(IinvW(rt), r))
        jt = min(0.4 * jn, vtLen / kt)              // 摩擦系数 0.4
        J = sub(J, mul(t, jt))
    vel = add(vel, mul(J, 1/mass))
    angvel = add(angvel, IinvW(cross(r, J)))
pos = add(pos, mul(n, pen * 0.8))                  // 位置修正（不论 vn 正负都要做）
```

`Track` 需要额外导出 `leftAt(p: Projection): V3`：返回 `normalize(lerp(left[a], left[b], f))`，y 分量取 0（和 `project` 内部的算法相同）。

**参考实现**：`reference/collision_reference.py`（`resolve_barriers`、`apply_contact`、`resolve_body_ground`）。TS 版放在 `src/physics/collision.ts`，函数名为 `resolveBarriers`、`applyContact`、`resolveBodyGround`，逐行移植。

**单元测试**（`tests/unit/collision.test.ts`）：移植 `collision_reference.py` 的 `__main__` 场景（测试赛道 `TEST_TRACK`，hatch 以 20 m/s 分别按 90°、60°、120° 撞向左侧护栏），断言：

| 角度 | hit_step | vz（命中后 0.5 s） | maxpen |
|---|---|---|---|
| 90 | 94 ± 2 | 2.86 ± 0.3 | < 0.05 |
| 60 | 107 ± 2 | 0.37 ± 0.3 | < 0.08 |
| 120 | 107 ± 2 | 0.37 ± 0.3 | < 0.08 |

另外断言全程没有 NaN。

## 3.7 车身触地（翻车保护）—— `src/physics/collision.ts`

车身局部 4 个点：`[±0.9, +0.55, ±2.0]`（车顶四角）和 4 个点 `[±0.9, -0.25, ±2.1]`（底盘四角），共 8 个点。每个物理步：

```
for each point Pi:
    Pw = pos + qRot(q, Pi)
    g = ground(Pw.x, Pw.z)
    pen = g.height - Pw.y
    if pen > 0:
        applyContact(vehicle, Pw, g.normal, pen, 0.1, 0.6)   // 与 3.6 相同的冲量 + 位置修正
```

## 3.8 重置车辆

`resetToTrack(vehicle, track, s)`：

```
i = round(s / track.step) mod track.count
P = track.pos[i]; T = track.tan[i]
yaw = atan2(T.x, T.z)                 // 车头 +Z 对准切线方向
vehicle.reset([P.x, track.height(P.x, P.z), P.z], yaw)
```

`reset` 会把车放在 `cgHeight + 0.02` 的高度，速度清零，档位设为 1。

触发方式：

1. 玩家按"重置"键（冷却 1.5 s）：`s` 取当前进度 `progressS`，本圈标记为无效。
2. 车身向上方向 `qRot(q,[0,1,0]).y < 0.3` 持续 3 s 时自动重置，规则同上。
3. 起跑：`s = startS - spawnBehindStart`。
