## 4.2 赛道网格 —— `src/track/trackMesh.ts`

导出 `buildTrackMeshes(track: Track, mats: TrackMaterials): THREE.Group`。

### 4.2.1 横截面

对每个采样点 i，按下列横向偏移 `d` 生成顶点（从左到右，`d` 为正表示左侧）：

```
hw = track.hw[i];  R = data.runoffWidth;  K = kerb[i] ? 1.0 : 0.0
条带 A 沥青路面：d ∈ [ +hw, -hw ]，横向等分 8 份（共 9 个顶点）
条带 B 左路缘：  d ∈ [ hw+K, hw ]      （K=0 时宽度为 0，照样生成，三角形退化无妨）
条带 C 右路缘：  d ∈ [ -hw, -hw-K ]
条带 D 左缓冲区：d ∈ [ hw+R, hw+K ]
条带 E 右缓冲区：d ∈ [ -hw-K, -hw-R ]
条带 F 左路肩外坡：d ∈ [ hw+R+vergeWidth, hw+R ]，外缘高度 = 内缘高度 - vergeDrop
条带 G 右路肩外坡：对称
条带 H 左裙边：从条带 F 的外缘竖直向下 2.0 m（同一 x、z，y 减 2.0）
条带 I 右裙边：对称
```

顶点位置：`P = pos[i] + left[i] * d`，`y = track.height(P.x, P.z)`。条带 F、G 的外缘点：`y = 内缘 y - terrain.vergeDrop`。

为了防止 z-fighting：路缘 y 加 0.015，沥青 y 加 0.010，缓冲区 y 加 0.0。

### 4.2.2 UV

- 沥青：`u = d / 8`，`v = s[i] / 8`（横向与纵向均每 8 m 重复一次纹理）。
- 路缘：`u = 0..1` 横向，`v = s[i] / 2`（红白块每 1 m 交替，由贴图本身实现，见 §4.3）。
- 缓冲区和外坡：`u = d / 4`，`v = s[i] / 4`（平铺）。

### 4.2.3 网格与材质

条带按材质合并为 4 个 `THREE.Mesh`：`asphalt`(A)、`kerb`(B+C)、`runoff`(D+E，草地和砾石**各一个 mesh**，按每个采样点的 `runoffSurface(s)` 分到对应 mesh)、`verge`(F+G+H+I，用草地材质)。

闭合：最后一个采样点连回第 0 个点（索引取模）。法线用 `geometry.computeVertexNormals()`。全部 `receiveShadow = true`，`castShadow = false`。

## 4.3 路缘贴图 —— `src/track/kerbTexture.ts`

用 Canvas 程序生成，不需要素材：64×256 px，纵向每 128 px 一个色块，交替使用 `#C8102E`（红）和 `#F2F2F2`（白），横向最外侧 6 px 画 `#2A2A2A` 细边。`CanvasTexture`，`wrapS = wrapT = RepeatWrapping`，`colorSpace = SRGBColorSpace`，`anisotropy` 取画质设置里的值。材质：`MeshStandardMaterial({ map, roughness: 0.55, metalness: 0 })`。

## 4.4 护栏 —— `src/track/barriers.ts`

左右各一条，沿采样点生成，横向位置 `d = ±(hw + runoffWidth)`。

### wall（valley）

混凝土墙：截面为宽 0.4 m、高 `barrier.height`（1.0 m）的矩形，底部向下延伸 2.0 m（埋进地里，遮住缝隙）。墙内侧面贴在 `d = ±(hw+R)` 上，向外侧加厚。材质 `concrete`（见 05 §5.4）。UV：`u = s/2`，`v = 高度/2`。`castShadow = true`，`receiveShadow = true`。

### guardrail（coast）

- 波形梁：截面采用 0.31 m 高、总深约 0.08 m 的双波折板，中心离地 0.55 m，内侧面贴在 `d = ±(hw+R)`。材质为金属：`MeshStandardMaterial({ color: '#9EA3A8', metalness: 0.6, roughness: 0.45 })`。
- 立柱：每 4 m 一根，`BoxGeometry(0.12, 0.9, 0.12)`，中心离地 0.45 m，向外偏 0.10 m。所有立柱放进一个 `InstancedMesh`，颜色 `#7D8187`，metalness 0.8，roughness 0.5。

## 4.5 地形 —— `src/track/terrain.ts`

导出 `buildTerrain(track: Track, quality: 'low'|'medium'|'high', mats): { mesh: THREE.Mesh; heightAt: (x: number, z: number) => number }`。

`heightAt` 对顶点高度网格做**双线性插值**（范围外取最近边缘的值），供景物摆放和相机防穿地使用。

### 4.5.1 网格

- 正方形，边长 `terrain.size`（3200 m），中心 = 赛道所有采样点 x、z 包围盒的中心。
- 分段数：low 128，medium 192，high 256（顶点数 = 分段 + 1 的平方）。
- 用 `PlaneGeometry(size, size, n, n)`，先 `rotateX(-Math.PI/2)`，再平移到中心，然后逐顶点计算高度。

### 4.5.2 顶点高度

对每个顶点 (x, z)：

```
// 1) 到中心线的水平距离 dist 和最近点 i（粗搜 + 细搜）
best = +∞
for j in 0, 4, 8, ... < count:          // 每 4 个采样点取一个
    d2 = (pos[j].x-x)² + (pos[j].z-z)²; 记下最小的 j0
for j in j0-4 .. j0+4（取模）:            // 在附近 9 个点里细搜
    同样求最小，得到 i 和 dist = sqrt(d2)

edge = hw[i] + runoffWidth + vergeWidth     // 路肩外缘到中心线的距离
edgeY = pos[i].y - vergeDrop - max(0, edge - hw[i]) * DRAIN_SLOPE   // 路肩外缘高度（近似）

if dist <= edge:
    h = edgeY - 0.6                          // 赛道正下方：压低 0.6 m，保证不穿出路面
else:
    t = smoothstep(edge, edge + blendDistance, dist)
    h = lerp(edgeY - 0.2, farField(x, z), t)
```

### 4.5.3 远景高度 farField

噪声定义在 `src/math/noise.ts`，必须完全按下面实现：

```ts
// 整数哈希 → [0,1)
export function hash2(ix: number, iz: number, seed: number): number {
  let h = (Math.imul(ix, 374761393) + Math.imul(iz, 668265263) + Math.imul(seed, 2147483647)) | 0;
  h = Math.imul(h ^ (h >>> 13), 1274126177);
  h = h ^ (h >>> 16);
  return (h >>> 0) / 4294967296;
}
// 值噪声，输出 [-1, 1]，使用 smoothstep 插值
export function valueNoise(x: number, z: number, seed: number): number {
  const ix = Math.floor(x), iz = Math.floor(z);
  const fx = x - ix, fz = z - iz;
  const ux = fx * fx * (3 - 2 * fx), uz = fz * fz * (3 - 2 * fz);
  const a = hash2(ix, iz, seed), b = hash2(ix + 1, iz, seed);
  const c = hash2(ix, iz + 1, seed), d = hash2(ix + 1, iz + 1, seed);
  return ((a + (b - a) * ux) + ((c + (d - c) * ux) - (a + (b - a) * ux)) * uz) * 2 - 1;
}
// fBm：振幅每层减半，频率每层翻倍，结果归一化到约 [-1, 1]
export function fbm(x: number, z: number, octaves: number, seed: number): number {
  let sum = 0, amp = 1, freq = 1, norm = 0;
  for (let o = 0; o < octaves; o++) { sum += amp * valueNoise(x * freq, z * freq, seed + o * 1013); norm += amp; amp *= 0.5; freq *= 2; }
  return sum / norm;
}
```

```
farField(x, z):
  f = terrain.farField; seed = scenery.seed
  n = fbm(x * f.frequency, z * f.frequency, f.octaves, seed)
  if f.type == 'hills':
      return f.base + f.amplitude * (0.5 + 0.5 * n)          // valley：0 ~ 45 m 的山丘
  if f.type == 'coast':
      return clamp((z - f.coastZ) * f.coastSlope, f.minHeight, f.maxHeight) + f.amplitude * n
      // coast：z 小于 coastZ(-520) 的方向逐渐降到海平面以下，形成海岸
```

### 4.5.4 地形材质

草地和岩石按坡度混合，地形接收阴影。见 05 §5.4。

海岸地形按相对海平面的世界高度 `y` 着色。干沙为 `vec3(0.62, 0.55, 0.42)`，在 0.4–1.6 m 过渡到原地形。湿沙亮度为干沙的 0.55 倍，在 0.05–0.45 m 过渡到干沙。灰白浪花使用 `vec3(0.86, 0.88, 0.86)`。两层值噪声以频率 1.8、6.2 和权重 0.6、0.4 合成 `n`。泡沫覆盖率为 `smoothstep(0.45, 0.75, n) * (1.0 - smoothstep(0.0, 0.22, abs(y + 0.02)))`。冲刷痕迹在湿沙上随高度渐隐，到 0.45 m 消失，两层合计混合比例最高为 0.8。

## 4.6 景物 —— `src/track/scenery.ts`

### 4.6.1 随机数

`src/math/rng.ts`：

```ts
export function mulberry32(seed: number): () => number {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
```

### 4.6.2 摆放算法（树和石头分别执行一次）

```
rng = mulberry32(seed + (kind == 'trees' ? 0 : 7777))
cfg = scenery.trees 或 scenery.rocks
baseDensity = 树按赛道取值（valley 0.85，coast 0.45），石头取 cfg.density
candidates = []
对地形范围内以 cfg.spacing 为间距的网格点 (gx, gz)，按 gx 外层、gz 内层的顺序遍历：
    x = gx + (rng() - 0.5) * cfg.spacing * 0.9
    z = gz + (rng() - 0.5) * cfg.spacing * 0.9
    r = rng()                       // 每个网格点固定消耗 3 次 rng()，不论是否采用
    i, dist = 到中心线的最近点和距离（同 §4.5.2 的粗搜 + 细搜）
    fromBarrier = dist - (hw[i] + runoffWidth)
    if fromBarrier < cfg.minFromBarrier or fromBarrier > cfg.maxFromBarrier: continue
    density = baseDensity * (1 - 0.6 * smoothstep(cfg.minFromBarrier, cfg.maxFromBarrier, fromBarrier))
    if r >= density: continue
    y = heightAt(x, z)
    if sea != null and y < sea.level + 1.0: continue
    y -= (kind == 'trees' ? 0.3 : 0.2)          // 稍微埋进地面，避免悬空
    candidates.push({ x, y, z, fromBarrier, model: cfg.models[floor(rng2 * models.length)] })
      // rng2 = 对 (x, z) 再调用 hash2(round(x*10), round(z*10), seed) 得到的值（不消耗 rng）
```

实例绕 Y 轴旋转 `hash2(round(x), round(z), seed+1) * 2π`。石头缩放取 `0.8 + 0.4 * hash2(round(x), round(z), seed+2)`。树木在 0.6–1.5 倍内等比缩放。以每棵树为中心，检查 48 m 内八个方向的邻树。相对两侧都有邻树的林心长得较高，临空的林缘长得较矮。每簇有两棵以上时选一棵优势木，六棵以上选两棵，缩放为 1.38–1.5 倍。近景模型、远景贴片和树冠遮光计算共用每棵树的尺寸。

按 `fromBarrier` 从小到大排序后截断。低、中、高画质下树木上限分别为 800、4000、9000 棵，石头上限分别为 150、400、800 块。

树按空间分区和树种建立实例批次，其他景物每种模型一个 `THREE.InstancedMesh`（如果模型包含多个 mesh，每个子 mesh 各建一个 `InstancedMesh`，共用同一组矩阵）。树：`castShadow = true`（low 画质为 false）；石头：`castShadow = false`。

缺少 GLB 时，近景树使用枝梢下垂的云杉、窄尖塔形的银冷杉和枝端向上生长的高山五针松。远景使用同树种透明贴图，贴图缺失时保留几何树形。近景枝叶和远景树贴图均使用无自发光的 Lambert 材质，亮度和色调随赛道光照变化。石头用 `IcosahedronGeometry(1.2, 0)`，颜色 `#7A7A72`，y 方向缩放 0.6。[云杉谷林地](../screenshots/valley-forest.png) · [海岸顺光](../screenshots/coast-forest-frontlit.png) · [海岸逆光](../screenshots/coast-forest-backlit.png)

### 4.6.3 树叶透光与远景树林

枝叶补光取自当前天空预过滤环境图上半球的漫反射颜色，强度随赛道环境光变化。逆光时，叶片朝太阳的视线夹角、冠缘位置和贴图中周围针叶的覆盖率决定透光强度。树干不透光。树冠沿垂直于阳光的方向取左、中、右三条采样线，分别计算山坡与上游树冠遮住的高度。近处枝叶还使用太阳的动态阴影贴图。在移动阴影贴图的范围以外，地形和邻树的遮挡仍有效。

沿护栏 260 m（云杉谷）或 220 m（灯塔海岸）以外开始铺远林，延伸到地形边界。16 m 抖动网格上叠加两种尺度的噪声形成林地和林隙。高画质下，云杉谷的种植概率为 `0.78 * smoothstep(-0.43, 0.32, grove)`，灯塔海岸为 `0.75 * smoothstep(-0.30, 0.48, grove)`。海平面以上 3.5 m 内的沙滩和坡度超过 0.70 的陡坡不参与种植。近树和远林分别计数。远林在低、中、高画质的上限分别为 2000、6000、12000 棵，各档位从同一组分布于整片地形的地点取样。

远林复用现有树种的交叉贴片，混合树种共享一张图集。每块 800 × 800 m 的林地使用一个可视锥剔除的实例网格，随场景雾衰减，不写入动态阴影贴图。中画质的近树使用同树种的镂空轮廓投射阴影。[海岸逆光](../screenshots/fix3-coast-backlit.png) · [海岸顺光](../screenshots/fix3-coast-frontlit.png) · [山谷顺光](../screenshots/fix3-valley-frontlit.png) · [山谷逆光](../screenshots/fix3-valley-backlit.png)

云杉、冷杉和五针松的木质主梢止于树冠内部。靠近顶端的枝层加密，围绕中心针叶逐层收尖。交叉贴片上端取同树种照片里有枝叶的部分，沿尖顶轮廓投影。[山谷树尖近景](../screenshots/fix4-valley-frontlit-close.png) · [山谷顺光](../screenshots/fix4-valley-frontlit.png) · [山谷逆光](../screenshots/fix4-valley-backlit.png) · [海岸顺光](../screenshots/fix4-coast-frontlit.png) · [海岸逆光](../screenshots/fix4-coast-backlit.png)

## 4.8 海面 —— `src/render/water.ts`（仅 coast）

## 4.9 小地图数据

`track.minimapPath(size: number, padding: number): string`：把所有采样点的 (x, z) 缩放到 `size×size` 的 SVG 坐标（保持宽高比，四周留 `padding`），**z 轴向上**（SVG 的 y = size - 缩放后的 z），返回 `M x0 y0 L x1 y1 ... Z` 字符串，坐标保留 1 位小数。同时提供 `minimapPoint(x, z)` 用同一个变换返回 `[px, py]`。
