# 05 渲染与画面

## 5.1 渲染器 —— `src/render/renderer.ts`

```ts
const renderer = new THREE.WebGLRenderer({ antialias: false, powerPreference: 'high-performance', stencil: false, depth: true });
renderer.setPixelRatio(Math.min(window.devicePixelRatio, QUALITY[q].maxPixelRatio));
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.outputColorSpace = THREE.SRGBColorSpace;
renderer.toneMapping = THREE.NoToneMapping;       // 色调映射交给后期的 ToneMappingEffect
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = q === 'high' ? THREE.PCFSoftShadowMap : THREE.PCFShadowMap;
```

- canvas 插入到 `<div id="game">` 中，CSS `position:fixed; inset:0`。
- 监听 `resize`，同步更新 renderer、composer 和相机的 aspect。
- `scene.fog = new THREE.Fog(fogColor, fogNear, fogFar)`；`camera.far` 取 `QUALITY[q].viewDistance`。
- 曝光：**不用** `toneMappingExposure`。改为乘到光照上：`sun.intensity = sunIntensity * exposure`、`scene.environmentIntensity = ambientEnvIntensity * exposure`、`scene.backgroundIntensity = exposure`。

## 5.2 环境光与天空 —— `src/render/environment.ts`

导出 `async setupEnvironment(scene, renderer, track, assets): Promise<{ sun: THREE.DirectionalLight; update(carPos: THREE.Vector3): void; dispose(): void }>`

### 有 HDRI 时

```ts
const tex = await new RGBELoader().loadAsync(url);   // three/examples/jsm/loaders/RGBELoader.js
tex.mapping = THREE.EquirectangularReflectionMapping;
const pmrem = new THREE.PMREMGenerator(renderer);
scene.environment = pmrem.fromEquirectangular(tex).texture;
scene.background = tex;
// 让 HDRI 里的太阳和平行光方向对齐：
const thetaS = (sunU - 0.5) * 2 * Math.PI;            // sunU 来自 manifest（HDRI 中太阳所在像素列 / 图片宽度）
const thetaD = Math.atan2(sunDir[2], sunDir[0]);
const psi = thetaS - thetaD;
scene.environmentRotation.set(0, psi, 0);
scene.backgroundRotation.set(0, psi, 0);
```

**对齐校验**（T31 的验收步骤）：`psi = thetaS - thetaD` 这个符号规划方已经在 three 0.169 + 无头 Chromium 中实测确认（3 个方向全部对准），**不要改动**。URL 带 `?debugSun=1` 时，在 `camera.position + sunDir * 900` 处画一个半径 12、`MeshBasicMaterial({ color: '#FF00FF', fog: false })` 的球，截图后品红球应该落在 HDRI 的太阳上。如果没有对上，原因一定是 manifest 里的 `sunU` 填错了：在 BLOCKERS.md 记一条，请用户核对 `sunU`，**代码不改**。

### 没有 HDRI 时（占位）

用 `three/examples/jsm/objects/Sky.js`：

```ts
const sky = new Sky(); sky.scale.setScalar(10000);
const u = sky.material.uniforms;
u.turbidity.value = skyFallback.turbidity; u.rayleigh.value = skyFallback.rayleigh;
u.mieCoefficient.value = skyFallback.mieCoefficient; u.mieDirectionalG.value = skyFallback.mieDirectionalG;
u.sunPosition.value.set(sunDir[0], sunDir[1], sunDir[2]);
scene.add(sky);
// 环境光：用一个只包含 sky 的临时场景生成 PMREM
const envScene = new THREE.Scene(); envScene.add(sky.clone());
scene.environment = new THREE.PMREMGenerator(renderer).fromScene(envScene, 0, 0.1, 20000).texture;
```

Sky 材质不受雾影响，这一点可以接受。

### 太阳光

```ts
const sun = new THREE.DirectionalLight(sunColor, sunIntensity * exposure);
sun.castShadow = QUALITY[q].shadows;
sun.shadow.mapSize.set(QUALITY[q].shadowMapSize, QUALITY[q].shadowMapSize);
const R = QUALITY[q].shadowRange;
Object.assign(sun.shadow.camera, { left: -R, right: R, top: R, bottom: -R, near: 1, far: 800 });
sun.shadow.bias = -0.0004; sun.shadow.normalBias = 0.02;
scene.add(sun, sun.target);
```

### 阴影跟随与防抖（`update(carPos)`，每帧调用）

```ts
const dir = new THREE.Vector3(...sunDir).normalize();
const right = new THREE.Vector3().crossVectors(dir, new THREE.Vector3(0, 1, 0)).normalize();
const up = new THREE.Vector3().crossVectors(right, dir).normalize();
const texel = (2 * R) / mapSize;
const x = Math.round(carPos.dot(right) / texel) * texel;
const y = Math.round(carPos.dot(up) / texel) * texel;
const z = carPos.dot(dir);
const snapped = right.clone().multiplyScalar(x).add(up.clone().multiplyScalar(y)).add(dir.clone().multiplyScalar(z));
sun.target.position.copy(snapped);
sun.position.copy(snapped).addScaledVector(dir, 400);
sun.target.updateMatrixWorld();
```

## 5.3 材质 —— `src/render/materials.ts`

导出 `createMaterials(assets, quality): TrackMaterials`，返回 `{ asphalt, kerb, grass, gravel, concrete, terrain }`。

| 材质 | 有素材时 | 占位（素材缺失） |
|---|---|---|
| asphalt | `MeshStandardMaterial({ map: asphalt_albedo, normalMap: asphalt_normal, roughnessMap: asphalt_rough, roughness: 1, metalness: 0 })`，`normalScale` = (0.8, 0.8) | `color '#3A3C3F', roughness 0.9` |
| kerb | 见 04 §4.3（程序生成） | 同左 |
| grass | albedo + normal，`roughness 1` | `color '#4E6B34', roughness 1` |

| concrete | albedo + normal + rough | `color '#9E9E98', roughness 0.85` |

## 5.4 地形材质（坡度混合）

`MeshStandardMaterial({ map: grassAlbedo, roughness: 1, metalness: 0 })`，再用 `onBeforeCompile` 注入以下代码：

```ts
material.onBeforeCompile = (shader) => {
  shader.uniforms.rockMap = { value: rockAlbedo };          // 占位时为 1×1 纯色 DataTexture '#6E6A63'
  shader.uniforms.grassTint = { value: new THREE.Color(1, 1, 1) };
  shader.vertexShader = shader.vertexShader
    .replace('#include <common>', '#include <common>\nvarying vec3 vWPos;\nvarying float vWNy;')
    .replace('#include <worldpos_vertex>', '#include <worldpos_vertex>\nvWPos = (modelMatrix * vec4(transformed, 1.0)).xyz;\nvWNy = normalize(mat3(modelMatrix) * objectNormal).y;');
  shader.fragmentShader = shader.fragmentShader
    .replace('#include <common>', '#include <common>\nuniform sampler2D rockMap;\nvarying vec3 vWPos;\nvarying float vWNy;')
    .replace('#include <map_fragment>', `
      vec4 g1 = texture2D(map, vWPos.xz / 6.0);
      vec4 g2 = texture2D(map, vWPos.xz / 41.0);
      vec3 grass = g1.rgb * (0.7 + 0.6 * g2.g);
      vec3 rock = texture2D(rockMap, vWPos.xz / 9.0).rgb;
      float k = smoothstep(0.92, 0.78, vWNy);
      diffuseColor.rgb *= mix(grass, rock, k);
    `);
};
```

注意：`worldpos_vertex` 只在某些宏开启时才计算 `worldPosition`，所以这里自己用 `modelMatrix * vec4(transformed,1.0)` 计算，不依赖它。这段注入代码规划方已经在 three 0.169 中实测：可以编译，平地显示草地色，45° 斜坡显示岩石色。占位纹理为 1×1 的 `DataTexture`：`map` 用 '#4E6B34'，`rockMap` 用 '#6E6A63'，都设置 `colorSpace = SRGBColorSpace` 和 `needsUpdate = true`。

## 5.5 车辆显示 —— `src/render/carView.ts`

### 5.5.1 层级结构

```
carRoot (Group)                       ← 每帧：position/quaternion = 物理插值位姿（质心）
 └─ modelOffset (Group)               ← position = (0, -cgHeight, zMid)，其中 zMid = (mount[FL].z + mount[RL].z) / 2
     └─ model (GLB 场景根节点或占位车)
         ├─ body ...
         ├─ wheel_FL / wheel_FR / wheel_RL / wheel_RR
         └─ （可选）caliper_FL ...
```

zMid 的值：hatch -0.312，coupe -0.053，rally -0.157（由数据算出，不要硬编码，用公式）。

### 5.5.2 车轮更新（每帧）

```ts
for (i of 0..3) {
  const w = vehicle.wheels[i], m = cfg.wheels[i].mount;
  node.position.set(m[0], m[1] - w.len + cgHeight, m[2] - zMid);   // 模型坐标
  qSteer.setFromAxisAngle(Y, w.steer);
  qSpin.setFromAxisAngle(X, w.rot);
  node.quaternion.copy(qSteer).multiply(qSpin).multiply(restQuat[i]);  // restQuat = 加载时节点自带的旋转
  caliper?.position.copy(node.position); caliper?.quaternion.copy(qSteer).multiply(caliperRestQuat[i]);
}
```

`w.len` 也要插值：保存上一步的 len，按物理插值的 alpha 做 `lerp`。`w.rot` 直接用最新值。

### 5.5.3 材质替换（加载后执行一次）

遍历模型中所有 mesh 的材质，**按材质名**处理（大小写敏感）：

| 材质名 | 替换为 |
|---|---|
| `paint` | 所有 `paint` 共用一个 `MeshPhysicalMaterial({ color: 当前涂装, metalness: 0.35, roughness: 0.28, clearcoat: 1.0, clearcoatRoughness: 0.04 })`。换涂装时只改这个共享材质的 `color` |
| `glass` | `MeshPhysicalMaterial({ color: '#0A0C10', metalness: 0, roughness: 0.05, transparent: true, opacity: 0.45, envMapIntensity: 1.5 })` |
| `light_brake` | 保留原材质，设置 `emissive = '#FF1A1A'`。不刹车时 `emissiveIntensity = 0.4`，`brake > 0.05` 时为 4.0 |
| `light_head` | 保留原材质，`emissive = '#FFF4E0'`，`emissiveIntensity`：coast 2.0，valley 0.3 |
| `light_tail` | 保留原材质，`emissive = '#B00000'`，`emissiveIntensity = 0.8` |
| 其他 | 不变 |

所有 mesh：`castShadow = true; receiveShadow = true`。

### 5.5.4 占位车 —— `src/render/placeholderCar.ts`

`buildPlaceholderCar(cfg): THREE.Group`。节点名和材质名必须与真实模型规范一致（见 09 §9.3），这样 carView 的代码对占位车和真实模型完全一样。模型坐标（原点在两轴中点下方的地面，+Z 向前）：

| 节点 | 几何 | 位置 | 材质名 / 颜色 |
|---|---|---|---|
| body | `Box(1.80, 0.62, 4.20)` | (0, 0.62, 0) | `paint` |
| body/cabin | `Box(1.50, 0.50, 2.00)` | (0, 1.17, -0.25) | `glass` |
| body/brake_L、brake_R | `Box(0.30, 0.10, 0.04)` | (±0.65, 0.80, -2.11) | `light_brake`（基础色 `#550000`） |
| body/head_L、head_R | `Box(0.35, 0.12, 0.04)` | (±0.60, 0.72, 2.11) | `light_head`（基础色 `#DDDDDD`） |
| wheel_XX | `Cylinder(R, R, width, 24)` 绕 Z 轴旋转 90°（**旋转写进 geometry**，不写在节点上），轮毂另加一个 `Cylinder(R*0.62, R*0.62, width+0.01, 12)`，颜色 `#9A9DA3`，metalness 0.8 | (±track/2, R, ±wheelbase/2) | 轮胎 `#151515`，roughness 0.9 |

其中 `R = cfg.wheel.radius`，`width = cfg.wheel.width`，`track = mount[FL].x * 2`，`wheelbase = mount[FL].z - mount[RL].z`。

## 5.6 相机 —— `src/render/cameraRig.ts`

`PerspectiveCamera(fov, aspect, 0.1, viewDistance)`。四种模式，按 `C`（或手柄 Y、触屏按钮）循环切换：chase → chaseFar → hood → bumper → chase。

### chase / chaseFar（每帧，dt 为帧时间）

| 参数 | chase | chaseFar |
|---|---|---|
| distance | 5.6 | 7.6 |
| height | 1.75 | 2.40 |
| lookAhead | 2.0 | 2.5 |
| lookHeight | 0.9 | 1.0 |
| baseFov | 62 | 58 |
| speedFov（300 km/h 时额外增加的 fov） | 10 | 8 |

```
carPos = 插值后的车辆位置；fwd = qRot(q, [0,0,1])
flatFwd = normalize([fwd.x, 0, fwd.z])
// 航向平滑：速度 > 3 m/s 且倒车时（vel·fwd < -1）用 -flatFwd，避免镜头翻转；其他情况正常
smoothedFwd = normalize(lerp(smoothedFwd, flatFwd, expDecay(6, dt)))
desired = carPos - smoothedFwd * distance + [0, height, 0]
camPos = lerp(camPos, desired, expDecay(12, dt))
camPos.y = max(camPos.y, heightAt(camPos.x, camPos.z) + 0.4, (track.height(camPos.x, camPos.z) ?? -1e9) + 0.4)
lookAt = carPos + [0, lookHeight, 0] + smoothedFwd * lookAhead
fov = baseFov + speedFov * clamp(speedKmh / 300, 0, 1)，然后 fovSmoothed = lerp(fovSmoothed, fov, expDecay(4, dt))
```

切换模式或重置车辆时，`smoothedFwd = flatFwd`，`camPos = desired`（直接跳过去，不做平滑）。

### hood / bumper（刚性挂在车身上）

在模型坐标中的位置（相对 modelOffset 的原点）：

| 车 | hood | bumper |
|---|---|---|
| hatch | (0, 1.22, 0.35) | (0, 0.55, 2.20) |
| coupe | (0, 1.12, 0.45) | (0, 0.50, 2.25) |
| rally | (0, 1.25, 0.35) | (0, 0.58, 2.20) |

相机朝向 = 车身朝向（看向 +Z），fov 72，不随速度变化。为了减轻颠簸，相机的俯仰和侧倾取车身实际角度的 50%：`camQ = slerp(yawOnlyQ, bodyQ, 0.5)`，其中 `yawOnlyQ` 是只保留偏航角的四元数。

### 镜头抖动（只用于 chase/chaseFar）

```
speedAmp = 0.015 * clamp((speedKmh - 120) / 180, 0, 1)
impactAmp = impactAmp * exp(-8 * dt); if lastImpact > 0: impactAmp = max(impactAmp, 0.12 * clamp(lastImpact / 8000, 0, 1))
amp = speedAmp + impactAmp
offset = 相机局部 x 方向 * amp * valueNoise(t*9, 0, 1) + 相机局部 y 方向 * amp * valueNoise(t*9, 5, 1)
```

## 5.7 后期处理 —— `src/render/postfx.ts`

使用 `postprocessing` 库：

```ts
const composer = new EffectComposer(renderer, { frameBufferType: THREE.HalfFloatType, multisampling: 0 });
composer.addPass(new RenderPass(scene, camera));
if (q === 'low') {
  composer.addPass(new EffectPass(camera, new ToneMappingEffect({ mode: ToneMappingMode.ACES_FILMIC })));
  composer.addPass(new EffectPass(camera, new FXAAEffect()));
} else {
  composer.addPass(new EffectPass(camera,
    new BloomEffect({ intensity: 0.6, luminanceThreshold: 0.85, luminanceSmoothing: 0.2, mipmapBlur: true }),
    new VignetteEffect({ offset: 0.3, darkness: 0.45 }),
    new ToneMappingEffect({ mode: ToneMappingMode.ACES_FILMIC })));
  composer.addPass(new EffectPass(camera, new SMAAEffect({ preset: q === 'high' ? SMAAPreset.HIGH : SMAAPreset.MEDIUM })));
}
```

每帧调用 `composer.render(dt)`，不再调用 `renderer.render`。

## 5.8 幽灵车 —— `src/render/ghostView.ts`

- 克隆当前车的模型（`SkeletonUtils.clone` 不需要，直接 `model.clone(true)`），把所有材质替换成同一个 `MeshStandardMaterial({ color: '#7FD1FF', transparent: true, opacity: 0.35, depthWrite: false, roughness: 0.4, metalness: 0.1 })`。
- `castShadow = false; receiveShadow = false; renderOrder = 10`。
- 车轮：不做悬挂，只做旋转：`rot += (移动距离 / R)`，转向角为 0。
- 幽灵车与玩家车距离 < 6 m 时，透明度线性降到 0.12（距离 2 m 时达到 0.12）。
- 设置里关闭幽灵车，或当前组合没有存档时，`visible = false`。

## 5.9 渲染主循环顺序（`src/app.ts` 里每帧执行）

```
1. now = performance.now(); dt = min((now - last)/1000, 0.1)
2. input.poll()                                   // 读取手柄状态等
3. 比赛状态为 racing 或 countdown 时：world.advance(dt, ...)；countdown 期间物理照常运行，但输入强制为 { throttle: 0, brake: 1, steer: 0 }
4. carView.update(world.interpolated(), vehicle, alpha)
5. ghost.update(raceTime)
6. env.update(carPos)
7. cameraRig.update(dt, ...)
8. water?.update(dt)
9. audio.update(dt, vehicle, ...)
10. hud.update(...)
11. composer.render(dt)
12. quality.sample(dt)                             // 自动画质（见 10）
```
