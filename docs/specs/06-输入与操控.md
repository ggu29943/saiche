# 06 输入与操控

## 6.1 总体结构

```
keyboard.ts ─┐
gamepad.ts  ─┼─→ inputManager.ts ─→ 原始意图 RawIntent ─→ smoothing.ts ─→ steeringAssist.ts ─→ DriveInput
touch.ts    ─┘                       （按"最近活跃设备"选一个）
```

```ts
// src/input/types.ts
export type DeviceKind = 'keyboard' | 'gamepad' | 'touch';
export interface RawIntent {
  device: DeviceKind;
  steer: number;        // [-1,1] 目标值（键盘为 -1/0/1，手柄、触屏为连续值）
  throttle: number;     // [0,1]
  brake: number;        // [0,1]
  handbrake: number;    // 0 或 1
}
export type ActionEvent = 'shiftUp' | 'shiftDown' | 'camera' | 'reset' | 'pause' | 'ghost';
```

`inputManager` 对外提供：

- `poll(): void`：每帧调用一次，读取手柄状态并更新"最近活跃设备"。
- `intent(): RawIntent`：当前活跃设备的原始意图。
- `consumeEvents(): ActionEvent[]`：取走自上次调用以来的所有离散事件。
- `activeDevice: DeviceKind`。

**最近活跃设备**规则：键盘上任意一个绑定键被按下 → keyboard；手柄任一轴的绝对值 > 0.25 或任一按键被按下 → gamepad；屏幕上任一 touchstart → touch。切换设备时 HUD 的操作提示随之变化。

## 6.2 键盘 —— `src/input/keyboard.ts`

用 `KeyboardEvent.code` 判断（不受输入法和键盘布局影响）：

| 功能 | 按键 |
|---|---|
| 油门 | `KeyW`、`ArrowUp` |
| 刹车 / 倒车 | `KeyS`、`ArrowDown` |
| 左转 | `KeyA`、`ArrowLeft` |
| 右转 | `KeyD`、`ArrowRight` |
| 手刹 | `Space` |
| 升档 / 降档（手动挡） | `KeyE` / `KeyQ` |
| 切换视角 | `KeyC` |
| 重置车辆 | `KeyR` |
| 暂停 | `Escape`、`KeyP` |
| 显示/隐藏幽灵车 | `KeyG` |

- steer 目标：左键按下得 +1，右键按下得 -1，同时按下得 0。
- 绑定键的 `keydown` 都要 `preventDefault()`（防止方向键和空格滚动页面）。
- `window` 的 `blur` 事件发生时清空所有按键状态。
- 离散事件只在 `keydown` 且 `!e.repeat` 时触发。

## 6.3 手柄 —— `src/input/gamepad.ts`

只支持 `gamepad.mapping === 'standard'` 的手柄；取 `navigator.getGamepads()` 里第一个不为 null 且 mapping 为 standard 的手柄。

| 功能 | 输入 |
|---|---|
| 转向 | 左摇杆 X 轴 `axes[0]`（**向左为负**，所以 steer = -axes[0]） |
| 油门 | RT `buttons[7].value` |
| 刹车 | LT `buttons[6].value` |
| 手刹 | A `buttons[0]` |
| 升档 / 降档 | RB `buttons[5]` / LB `buttons[4]` |
| 视角 | Y `buttons[3]` |
| 重置 | X `buttons[2]` |
| 暂停 | Start `buttons[9]` |
| 幽灵车 | Back/View `buttons[8]` |

转向曲线：

```
x = -axes[0]
if |x| < 0.08: x = 0
else: x = sign(x) * ((|x| - 0.08) / 0.92) ^ 1.6
```

扳机：`v < 0.04 ? 0 : (v - 0.04) / 0.96`。按键事件只在"上一帧未按下、这一帧按下"时触发一次。

## 6.4 触屏 —— `src/input/touch.ts` + `src/ui/touchOverlay.ts`

**显示条件**：`matchMedia('(pointer: coarse)').matches` 为 true，或者发生过任意一次 `touchstart`。竖屏时显示"请横屏"提示（`screens/rotate.ts`），游戏暂停。

**布局**（CSS 像素，横屏，基于视口，用 `env(safe-area-inset-*)` 留出安全区）：

| 元素 | 位置与尺寸 | 行为 |
|---|---|---|
| 转向区 | 左侧，`left: 0; bottom: 0; width: 45vw; height: 60vh`，透明 | 手指按下的点为原点 `x0`，`steer = clamp(-(x - x0) / 90, -1, 1)`（向左拖为正）。在原点处画一个直径 120 px 的半透明圆环，再画一个直径 56 px 的圆形滑块跟随手指（只在水平方向移动，范围 ±90 px）。松手 steer = 0 |
| 油门踏板 | `right: 24px; bottom: 24px; 96×176 px`，圆角 18 | 按住为 1，松开为 0 |
| 刹车踏板 | `right: 136px; bottom: 24px; 96×136 px` | 同上 |
| 手刹 | `right: 136px; bottom: 176px; 96×56 px` | 同上 |
| 升档 ▲ / 降档 ▼ | `right: 248px; bottom: 24px / 96px; 64×64 px` | 只在手动挡时显示，点击触发事件 |
| 暂停 ⏸、视角 🎥、重置 ↺ | 屏幕右上角，横向排列，每个 52×52 px，间距 10 px | 点击触发事件 |

- 每个元素用 `pointerdown/pointermove/pointerup/pointercancel` 并调用 `setPointerCapture`，支持多点触控。按 `pointerId` 区分手指。
- 整个覆盖层设置 `touch-action: none; user-select: none; -webkit-user-select: none`。
- 踏板按下时背景透明度从 0.25 变为 0.5，`transition: 60ms`。
- 踏板上的文字：油门「油门」，刹车「刹车」，手刹「手刹」（取自 strings.ts）。

## 6.5 平滑 —— `src/input/smoothing.ts`

只对**键盘和触屏**做平滑；手柄直接使用原始值。

```
// 每个物理步执行（dt = PHYSICS_DT）
throttle: 目标更大时以 4.0/s 上升，目标更小时以 6.0/s 下降
brake:    上升 5.0/s，下降 8.0/s
steer:
  target 与当前值同号且绝对值更大：以 2.2/s 向 target 移动
  其他情况（回正或反打）：以 5.0/s 向 target 移动
handbrake：不平滑
```

"以 r/s 移动"的意思是：`cur += clamp(target - cur, -r*dt, r*dt)`。

**测试**：`tests/unit/smoothing.test.ts`：键盘 steer 从 0 到 1 用时 0.4545 s（±1 步）；从 1 回到 0 用时 0.2 s（±1 步）。

## 6.6 转向辅助 —— `src/input/steeringAssist.ts`

当前设备对应的 `settings.steeringAssist[device]` 为 true 时生效：

```
v = max(|vehicle.vel · fwd|, 1.0)
L = mount[FL].z - mount[RL].z                 // 轴距
dmax = cfg.steering.maxAngleDeg 换算成弧度
dlim = min(dmax, atan(L * 9.81 * 0.95 / (v*v)) + 0.8 * vehicle.ap)
steerOut = steerIn * (dlim / dmax)
```

`vehicle.ap` 是轮胎侧向峰值滑移角（构造时算好，约 0.138 rad）。转向辅助在平滑**之后**执行。

**测试**：`tests/unit/steeringAssist.test.ts`：hatch 在 100 km/h 时满舵输入 1.0 → 输出 0.2395（±0.002）；10 km/h 时输出 1.0。

## 6.7 组装 DriveInput

```
intent = inputManager.intent()
s = smoothing.step(intent, PHYSICS_DT)          // 手柄则 s = intent
steer = steeringAssist(s.steer, ...)
shift = 本物理步要消费的换挡事件（shiftUp → +1，shiftDown → -1，没有则 0；每个物理步最多消费一个）
DriveInput = { steer, throttle: s.throttle, brake: s.brake, handbrake: s.handbrake, shift, assists: settings.assists }
```

调试覆盖：`window.__apex.setInputOverride(x)` 设为非 null 时，直接用 x 的四个值替代 `s`（仍然经过转向辅助）。
