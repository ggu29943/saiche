# 07 游戏流程与 UI

## 7.1 界面状态机 —— `src/app.ts`

界面 id（同时作为 `window.__apex.state().screen` 的取值）：

```
title → mainMenu → carSelect → trackSelect → loading → countdown → racing ⇄ paused → results
                 ↘ settings（可以从 mainMenu 或 paused 进入，返回时回到来源界面）
                 ↘ help（从 mainMenu 进入）
```

| 界面 | 进入 | 离开 |
|---|---|---|
| title | 启动后 | 任意键 / 点击 / 手柄任意键 → mainMenu。**这一步同时创建 AudioContext**（浏览器要求用户手势） |
| mainMenu | | 「开始驾驶」→ carSelect；「设置」→ settings；「操作说明」→ help |
| carSelect | | 确认 → trackSelect；返回 → mainMenu |
| trackSelect | | 确认 → loading；返回 → carSelect |
| loading | | 加载完成 → countdown |
| countdown | | 3 s 后 → racing（计时从 GO 开始） |
| racing | | 暂停键 → paused；页面 `visibilitychange` 变为 hidden → paused |
| paused | | 「继续」→ racing；「重新开始」→ 原组合重新 countdown（不重新加载）；「设置」→ settings；「结束练习」→ results |
| results | | 「再来一次」→ countdown；「返回主菜单」→ mainMenu（释放赛道资源） |

每个界面是 `src/ui/screens/*.ts` 里的一个类，实现：

```ts
export interface Screen {
  id: string;
  mount(root: HTMLElement): void;   // 创建 DOM
  unmount(): void;                  // 移除 DOM、解绑事件
  onAction?(a: 'up' | 'down' | 'left' | 'right' | 'confirm' | 'back'): void; // 键盘/手柄导航
}
```

## 7.2 菜单导航 —— `src/ui/dom.ts`

- 键盘：方向键 / WASD → up/down/left/right；`Enter`、`Space` → confirm；`Escape`、`Backspace` → back。
- 手柄：十字键 `buttons[12..15]`（上下左右）或左摇杆（超过 0.6 时触发，触发后需回到 0.3 以下才能再次触发）→ 方向；A → confirm；B `buttons[1]` → back。
- 鼠标/触屏：直接点击。
- 焦点管理：每个界面有一个按钮列表 `focusables`，当前焦点项加上 class `is-focused`。up/down 在列表里移动（首尾循环），confirm 触发当前按钮。carSelect/trackSelect 的 left/right 用来切换车/赛道。
- 菜单切换时播放 UI 音效 `ui_move` / `ui_confirm` / `ui_back`（见 08）。

## 7.5 计圈与计时 —— `src/game/lapTimer.ts`

```ts
export class LapTimer {
  constructor(track: Track);
  reset(spawnS: number): void;            // lapDist = -(track.startS - spawnS)，即 -6
  start(): void;                           // GO 时调用：raceTime = 0, lapStart = 0
  /** 每个物理步调用 */
  step(dt: number, s: number, allWheelsOff: boolean): LapEvent[];
  invalidate(reason: 'offtrack' | 'reset'): void;
  readonly lap: number;                   // 当前圈号，从 1 开始
  readonly raceTime: number;              // 秒
  readonly lapTime: number;
  readonly lapDist: number;
  readonly invalid: boolean;
  readonly laps: { timeMs: number; sectorsMs: [number, number, number]; valid: boolean }[];
}
export type LapEvent =
  | { type: 'sector'; index: 0 | 1; timeMs: number }    // 跨过 S1 / S2 的终点
  | { type: 'lap'; timeMs: number; sectorsMs: [number, number, number]; valid: boolean }
  | { type: 'invalid'; reason: 'offtrack' | 'reset' };
```

算法（每个物理步）：

```
raceTime += dt
ds = s - sPrev
if ds >  L/2: ds -= L
if ds < -L/2: ds += L
sPrev = s
lapDist += ds
if allWheelsOff and not invalid: invalidate('offtrack')
for k in [1, 2]:                                   // 分段边界 = sectorFractions[k] * L
    if 本圈第 k 段还没记录 and lapDist >= sectorFractions[k] * L: 记录分段时间，产生 sector 事件
if lapDist >= L:
    lapDist -= L
    第 3 段时间 = 圈时间 - 前两段之和
    产生 lap 事件，把这一圈加入 laps
    lap += 1; lapStart = raceTime; invalid = false
```

`s` 是车辆质心在赛道上的投影进度（`track.project(pos.x, pos.z).s`）。投影失败（返回 null）时这一步不更新 `lapDist`。

`allWheelsOff`：4 个车轮都 `contact == true`，并且 surface 都属于 {grass, gravel}。

**测试**（`tests/unit/lapTimer.test.ts`）：用 valley，构造一串均匀前进的 s（每步前进 0.2 m，从 `startS - 6` 开始），断言：

- 第一个 lap 事件出现在累计行驶 `L + 6` m 时（±0.2 m）；
- 两个 sector 事件分别出现在 `0.3333 L + 6` 和 `0.6667 L + 6` 处；
- 倒退（s 减小）时 lapDist 减小，不会误判完成一圈；
- 中途调用 `invalidate` 后，这一圈的 `valid` 为 false，下一圈恢复 true。

## 7.6 幽灵车 —— `src/game/ghost.ts`

**录制**：每 8 个物理步（240/30 Hz）记录一帧：`[lapTime, lapDist, px, py, pz, qw, qx, qy, qz]`，共 9 个 float。每圈开始时清空。圈完成、本圈有效、并且比存档最佳快（或者还没有存档）时：

```
保存 BestRecord；把 Float32Array 转成 base64 存进 apex.ghost.v1.<track>.<car>
```

base64 转换：`btoa(String.fromCharCode(...new Uint8Array(f32.buffer)))` 在数组很大时会爆栈，**分块处理**，每块 0x8000 字节。

**回放**：每帧按当前 `lapTime` 用二分查找定位，取前后两帧插值（位置 lerp，四元数 nlerp）。lapTime 超过录像时长时隐藏幽灵车。每圈开始时从头播放。

**实时差值**：在幽灵数据里用二分查找按 `lapDist` 定位，插值得到最佳圈跑到同一距离时用的时间 `tBest`，`delta = lapTime - tBest`。`lapDist < 0`（起步线后方）时不显示。

## 7.7 其他游戏规则 —— `src/game/raceController.ts`

- **重置**（6.1 的 reset 事件）：冷却 1.5 s；调用 `resetToTrack(vehicle, track, s)`；`lapTimer.invalidate('reset')`；相机直接跳到新位置。
- **自动重置**：见 03 §3.8。
- **逆行**：`dot(fwd, tan(s)) < -0.5` 并且 `speed > 5 m/s` 持续 2 s → 显示「逆行」。条件不满足时立即隐藏。
- **新纪录**：圈完成且刷新个人最佳时，中央提示「新的个人最佳！1:22.101」，HUD 最佳时间变成 `--best` 色。
- **辅助状态**：把 `Settings.assists` 原样存进 `BestRecord.assists`，不区分排行。

## 7.8 选车展厅 —— 由 `src/ui/screens/carSelect.ts` 驱动 `src/render/showroom.ts`

- 独立的 `THREE.Scene`，复用同一个 renderer 和 composer 配置。
- 环境：如果有 `valley_sky.hdr` 就用它，并设置 `scene.backgroundBlurriness = 0.6; scene.backgroundIntensity = 0.25`；否则用 `three/examples/jsm/environments/RoomEnvironment.js` 生成 PMREM，背景为纯色 `#0B0E13`。
- 地面：半径 6 m 的圆盘 `CircleGeometry(6, 64)`，`MeshStandardMaterial({ color: '#15181E', roughness: 0.35, metalness: 0.2 })`，接收阴影。外面再套一个半径 40 m 的 `ShadowMaterial({ opacity: 0.35 })` 平面。
- 灯光：一盏 `DirectionalLight('#FFFFFF', 2.0)`，位置 (4, 8, 3)，开阴影，mapSize 2048，范围 ±5 m。
- 车：放在原点，以 0.25 rad/s 匀速绕 Y 轴转动；车轮静止，悬挂在静止高度（`len = restLength - mass*g*分配/stiffness`，直接用 `Vehicle` 落定 2 s 后的状态即可：构造一个平地 Vehicle，跑 480 步，读取 len）。
- 相机：位置 (4.6, 1.5, 4.6)，看向 (0, 0.55, 0)，fov 35。鼠标/触屏水平拖动时手动旋转车辆（每像素 0.008 rad），松手 2 s 后恢复自动旋转。

## 7.9 时间格式 —— `src/game/formatTime.ts`

```ts
formatLap(ms: number): string    // 83456 → "1:23.456"；5123 → "0:05.123"；负数不会出现
formatDelta(ms: number): string  // 234 → "+0.234"；-512 → "−0.512"（用 U+2212 减号）；0 → "±0.000"
```

**测试**：上面 5 个例子，再加上 `formatLap(600000)` → "10:00.000"。
