# 08 音频

全部用 Web Audio API，不使用 `<audio>` 标签，也不引入音频库。

## 8.1 音频图 —— `src/audio/audioEngine.ts`

```
[engine 各声部] → engineBus(Gain) ─┐
[轮胎/路面/风/撞击/换挡] → fxBus(Gain) ─┼→ master(Gain) → DynamicsCompressor → destination
[UI/倒计时提示音] → uiBus(Gain) ──┘
```

- `engineBus.gain = volume.engine`，`fxBus.gain = volume.effects`，`uiBus.gain = volume.effects`，`master.gain = volume.master`。
- Compressor：`threshold -14, knee 10, ratio 4, attack 0.003, release 0.25`。
- AudioContext 在 title 界面的第一次用户手势中创建（07 §7.1）。iOS 上在同一个手势里额外调用一次 `ctx.resume()`。
- 所有参数变化一律用 `param.setTargetAtTime(value, ctx.currentTime, timeConstant)`，timeConstant 默认 0.03。**不许**直接给 `.value` 赋值（会产生爆音）。
- 解码：`ctx.decodeAudioData(arrayBuffer)`。文件缺失或解码失败时，用 §8.4 的合成方案替代，并 `console.info` 一次。

## 8.2 引擎声 —— `src/audio/engineSound.ts`

素材（每辆车一组，见 09 §9.5）：3 个**带负载**的循环（on_low、on_mid、on_high）和 1 个**松油门**的循环（off_mid）。每个文件在 manifest 里标注录制时的转速 `rpm`。

每个文件对应一个 `AudioBufferSourceNode`（`loop = true`）接一个 `GainNode`，进入比赛时一起 `start()`，离开比赛时一起 `stop()`。

每帧更新：

```
load = 平滑后的油门：load += (target - load) * expDecay(10, dt)；target = limiterCut ? 0 : throttle * tcsScale
on = 按 rpm 升序排列的 3 个 on 声部
// 等功率交叉淡化
if rpm <= on[0].rpm: 只有 on[0] 有声音，g = 1
elif rpm >= on[2].rpm: 只有 on[2]，g = 1
else: 找到 rpm 所在的相邻两段 i, i+1；t = (rpm - on[i].rpm) / (on[i+1].rpm - on[i].rpm)
      g_i = cos(t * π/2)，g_{i+1} = sin(t * π/2)，其余为 0
每个 on 声部：gain = g * (0.35 + 0.65 * load)，playbackRate = clamp(rpm / 声部.rpm, 0.5, 2.0)
off 声部：gain = (1 - load) * 0.8，playbackRate = clamp(rpm / off.rpm, 0.5, 2.0)
```

换挡瞬间（`shiftTimer > 0`）：整个 engineBus 再乘以 0.7。

## 8.3 音效 —— `src/audio/sfx.ts`

| 名称 | 类型 | 规则 |
|---|---|---|
| tyre_skid | 循环 | `skid = clamp(max_i(s_i), 0, 1)`，其中 `s_i = max(0, |κ_i| - 0.9·kp) / 0.4 + max(0, |atan(β_i)| - 0.9·ap) / 0.3`，只统计 contact 为 true 且 surface 为 asphalt 或 kerb 的车轮。gain = `skid * 0.7 * min(1, speed / 8)`，playbackRate = `0.9 + 0.2 * skid` |
| surface_gravel | 循环 | gain = `(在 gravel 或 grass 上的车轮数 / 4) * min(1, speed / 20) * 0.6`，playbackRate = `0.8 + 0.4 * min(1, speed / 30)` |
| wind | 循环 | `w = clamp((speedKmh - 40) / 200, 0, 1)`，gain = `w * 0.5`，playbackRate = `0.8 + 0.4 * w` |
| impact_light / impact_heavy | 单次 | 每帧读取 `world.lastImpact`（清零由 app.ts 统一负责）。`> 1500` 时播放：`> 6000` 用 heavy，否则用 light；gain = `clamp(lastImpact / 9000, 0.2, 1)`；两次播放至少间隔 0.15 s |
| shift | 单次 | 档位变化时播放，gain 0.5 |
| beep_low / beep_high | 单次，合成 | 见 §8.4 |
| ui_move / ui_confirm / ui_back | 单次，合成 | 见 §8.4 |

`speed` 指 `|vel|`（m/s）。循环音效在进入比赛时 start，gain 初始为 0。

## 8.4 合成方案 —— `src/audio/synthEngine.ts`

### 引擎（素材缺失时）

气缸数：hatch 4、coupe 6、rally 4（常量表写在 synthEngine.ts 里）。点火频率 `f = rpm / 60 * cylinders / 2`。

```
osc1 = sawtooth(f)          gain 1.0
osc2 = square(f / 2)        gain 0.4
osc3 = sawtooth(2f)         gain 0.25
noise = 白噪声循环 buffer(2 s) → BiquadFilter bandpass(频率 2f, Q 4) → gain 0.05 * load
sum → WaveShaper(curve: 2048 点, y = tanh(2.5 x)) → BiquadFilter lowpass(频率 400 + 2600*load + 0.2*rpm, Q 0.8) → gain(0.12 + 0.18 * load) → engineBus
```

### 其他合成音

| 名称 | 合成方法 |
|---|---|
| tyre_skid | 白噪声 → bandpass 1100 Hz, Q 1.2 |
| surface_gravel | 棕噪声（白噪声做一阶积分 `b = (b + 0.02*white) / 1.02`，再乘 3.5）→ lowpass 600 Hz |
| wind | 白噪声 → bandpass 500 Hz, Q 0.5 |
| impact | 白噪声 burst 120 ms，增益包络从 1 以指数衰减（timeConstant 0.03）→ lowpass 900 Hz |
| shift | square 90 Hz，40 ms，包络同上 |
| beep_low | sine 660 Hz，180 ms，attack 5 ms，release 用 timeConstant 0.04 |
| beep_high | sine 1320 Hz，400 ms，同上 |
| ui_move | sine 880 Hz，30 ms，gain 0.15 |
| ui_confirm | sine 660 Hz 40 ms，接着 990 Hz 40 ms，gain 0.2 |
| ui_back | sine 990 Hz 40 ms，接着 660 Hz 40 ms，gain 0.2 |

beep 和 ui 音**始终使用合成**，不需要素材。

## 8.5 暂停与切后台

- 进入 paused：`ctx.suspend()`；回到 racing：`ctx.resume()`。
- `document.visibilitychange` 变为 hidden 时，先切到 paused。
