### 11.1.1 整圈驾驶测试（perf.test.ts）

在真实赛道上用一个自动驾驶控制器跑 24000 步（100 s，包含碰撞处理和计圈）。规划方已经用参考实现（`reference/drive_reference.py`）跑过：valley/hatch 行驶 2292.9 m，valley/coupe 2328.4 m，coast/rally 2429.9 m，三组都**没有任何一次撞墙**（maxpen = 0）。

初始化：车放在 `startS - 6` 处（03 §3.8），`assists = { abs: true, tcs: true, esc: true, autoGear: true }`，`lapDist = -6`。每一步：

```
p = track.project(pos.x, pos.z); i = p.a
R = 1 / max( max_{j=0..39} |curv[(i+j) % count]| , 1e-4 )
vt = min(45, sqrt(0.75 * 9.81 * R))                 // 目标速度
spd = dot(vel, qRot(q, [0,0,1]))
throttle = clamp((vt - spd) * 0.5, 0, 1);  brake = clamp((spd - vt) * 0.3, 0, 1)
j = (i + trunc(8 / track.step)) % count              // 瞄准前方 8 m 的采样点
headingError = wrapAngle(atan2(tan[j].x, tan[j].z) - atan2(fwd.x, fwd.z))
steer = clamp(-0.08 * p.d + 1.2 * headingError, -1, 1)
vehicle.step({ steer, throttle, brake, handbrake: 0, shift: 0, assists }, PHYSICS_DT)
resolveBarriers(...); resolveBodyGround(...)
按 07 §7.5 的方法累加 lapDist
```

断言（三组都要测）：`lapDist ≥ 2000`；`maxPen < 0.3`；全程没有 NaN；24000 步的总耗时除以 24000 < 0.15 ms。

> rng 和 hash2 的期望值是规划方用规格里的公式在 Node 22 中实际算出的。如果对不上，说明实现和规格不一致。

## 11.2 端到端测试（`tests/e2e/`）

desktop 运行 boot、viewer、drive、menu、loadtime、smoke、screenshots。mobile 使用 Pixel 7 横屏，运行 boot、smoke、touch、screenshots。各项目通过 01 §1.6 的 `testMatch` 选择对应的 spec。

`smoke.spec.ts`（desktop 和 mobile 两个 project 都要跑）：

1. 打开 `/`，等待 `window.__apex` 存在，断言 `state().screen === 'title'`，并且控制台没有 error。
2. 调用 `await window.__apex.startRace('valley', 'hatch')`，等待 screen 变为 `countdown`，再调用 `skipCountdown()`，等待 screen 变为 `racing`。
3. `setInputOverride({ steer: 0, throttle: 1, brake: 0, handbrake: 0 })`，等待 5 s。断言 `speedKmh > 60`，`pos` 有变化。
4. 截图保存到 `test-results/racing-valley.png`。
5. 换成 `('coast', 'rally')` 重复步骤 2–4，截图 `racing-coast.png`。
6. 全程收集 `page.on('console')` 中 type 为 error 的消息，最后断言数量为 0（**忽略**内容包含 `[assets] missing` 的消息，以及 `favicon` 404）。

`menu.spec.ts`（只跑 desktop）：

1. 在 title 按 `Enter` → mainMenu。
2. 按 `Enter`（默认焦点为「开始驾驶」）→ carSelect；按 `ArrowRight` 两次，断言选中 rally；`Enter` → trackSelect；`ArrowRight` → coast；`Enter` → loading，然后等到 countdown。
3. 进入 racing 后按 `Escape` → paused；按 `ArrowDown` 3 次 + `Enter`（「结束练习」）→ results。

## 11.3 人工验收清单（交付时由用户执行，Codex 在 T60 把它原样复制到 README）

- [ ] 三辆车手感有明显区别：hatch 转向不足、宽容；coupe 后驱，深踩油门出弯会甩尾（关闭 TCS 更明显）；rally 出弯牵引力最好。
- [ ] 关闭 ABS 后急刹会抱死（刹车声和打滑声），开启 ABS 时能边刹车边转向。
- [ ] 两条赛道各开 3 圈：没有掉出地图、没有穿墙、没有看到地形穿出路面。
- [ ] 撞墙后车会被弹回，不会卡在墙里。
- [ ] 跑出一个有效圈后，下一圈出现幽灵车，差值胶囊正常显示。
- [ ] 刷新页面后最佳成绩和设置都还在。
- [ ] 手柄：摇杆转向线性、扳机油门和刹车是线性的。
- [ ] 手机横屏可以操作，竖屏会提示旋转。
- [ ] 画质切换（低/中/高）立即生效，明显看得出差别。
- [ ] 放入真实车模后，车轮位置正确、转向和滚动方向正确、换涂装生效。
- [ ] 放入 HDRI 后，阴影方向和天空里的太阳方向一致。
